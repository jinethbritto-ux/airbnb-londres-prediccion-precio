# Datos

El archivo de datos **no se incluye en este repositorio** porque pesa unos 143 MB y GitHub no admite archivos de más de 100 MB.

## Cómo obtenerlo

1. Entra a la página del conjunto de datos en Kaggle:
   https://www.kaggle.com/datasets/mrnabiz/detailed-airbnb-listing-data-london-sep-2022
2. Descarga el archivo **`clean_df.csv`**.
3. Guárdalo en esta carpeta, como `data/clean_df.csv`.

> No abras ni guardes el archivo de nuevo con Excel: en español Excel cambia el separador y el archivo queda dañado.

## Qué contiene

| Característica | Valor |
|---|---|
| Fuente original | Inside Airbnb (anuncios de Londres, septiembre de 2022) |
| Publicado en Kaggle por | mrnabiz |
| Filas | 69.351 anuncios |
| Columnas | 52 (27 numéricas, 3 de fecha y 22 de texto o categóricas) |
| Variable objetivo | `price` (precio por noche, viene como texto, por ejemplo `$50.00`) |

El archivo original debe estar disponible para auditoría; el análisis nunca lo modifica.
